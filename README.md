# Listify
> A simple archiving tool for your Spotify playlists.

Welcome to Listify!  

- [Skip to Table of Contents](#table-of-contents)

My name is SPM, and I am a digital hoarder.  
It's something I try to work on, but, for some reason,
I have a need for things to be archived, in some way,
before I can comfortably consider deletion.
One of the ways I try to work on this unfortunate little
trait of mine is archiving miscellaneous things in as
space-saving a form as possible, and then getting rid of
the primary forms as I see fit. It provides me with some
odd comfort. Something's preserved in some way? Great!
Now I get to clean things up however I'd like, and if I
end up having regrets or needing to change things somewhere
down the line, I have some way of doing so.
